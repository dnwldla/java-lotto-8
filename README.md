# java-lotto-precourse

<h2>입력사항</h2>

- 구입 금액을 입력한다  
- 당첨번호와 보너스 번호를 입력한다  


<h2>구현사항</h2>

- 구입한 금액만큼 로또를 발행한다  
- 수익률을 계산한다  

<h2>고려사항</h2>

- 수익률은 소수점 둘째 자리에서 반올림한다  
- 로또의 범위는 1부터 45이다  
- 로또 번호와 보너스 번호는 중복되지 않는다  
- 로또 번호는 오름차순으로 정렬된다


<h2>예외사항</h2>

구입 금액을 입력할 때  

- 1000으로 나누어 떨어지지 않는다  


당첨번호, 보너스 번호를 입력할 때  

- 범위에 벗어나는 숫자를 입력한다  
- 당첨번호에 보너스 번호가 존재한다  


<h2>클래스 명세서</h2>

| 클래스명 | 역할 설명 |
|-----------|------------|
| **`Lotto`** | 로또 발행기에서 발급받은 번호를 관리한다. |
| **`BonusNumber`** | 사용자 입력에 의한 보너스 번호를 관리한다. |
| **`MainNumbers`** | 당첨 번호 6개를 관리한다. |
| **`WinningNumbers`** | 당첨 번호와 보너스 번호를 함께 관리한다. |
| **`LottoGenerator`** | 랜덤으로 당첨 번호 6개를 발급한다. |
| **`Calculator`** | 수익률을 계산한다. |
